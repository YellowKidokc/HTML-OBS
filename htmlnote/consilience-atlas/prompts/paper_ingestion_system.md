# Paper Ingestion — System Prompt (ingest-v1)

This is the on-disk, human-readable record of the cold ingestion prompts.
The authoritative runtime copies live in `atlas/ai/prompts.py` and every AI
output records its `prompt_version`.

## Firewall rule (spec X, AJ)
The cold Ascent passes (A, B, C) must **not** be told the expected
theological / Descent answer. Ascent must not be secretly given Descent's
answer. Framework projections (χ, Reference architecture, Descent) belong to a
later, clearly separated pass (D) that is **not** part of Milestone 1.

## Pass A — Source-preserving segmentation
Segment into addressable atom spans. Split when a span would need two
conflicting values on any classification axis. Preserve exact offsets.

## Pass B — Multi-axis classification
Classify on parallel axes (function, source, commitment, standing, dispute,
claim_family, modality, scope, provenance, reference_architecture E/N/F/T).
Never assume T is superior. Emit numeric confidence + basis.

## Pass C — Relations
depends_on / supports / contradicts / derives, justified from the text only.
